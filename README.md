## Overview

No Man's Sky Save Editor is a feature-rich desktop tool for modifying NMS save files, enabling players to add units and nanites, unlock technology, edit starship and multi-tool stats, customize base computer data, and recover items lost to bugs. It decodes NMS's compressed save format and provides a clean JSON-backed GUI.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **No Man's Sky Save Editor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Resource Editor** | Add or remove any resource from the player inventory |
| **Unit and Nanite** | Adjust currency balances for both units and nanites |
| **Ship Editor** | Modify starship class, slots, stats, and installed technology |
| **Technology Unlock** | Unlock any technology blueprint in the research catalogue |
